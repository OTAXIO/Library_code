# 机构知识库助手 0.4.3

只保留两个功能：**自动认领**、**自动导入 WOS 文献**。生产程序固定使用本库网页扩展与桌面 Bridge，不调用 Browser Skill、bsk、模型或第三方下载通道。

## 启动和连接

1. 将最新名单放在本目录，命名为 `list.xlsx`。关闭正在编辑它的 Excel。
2. 双击 `启动助手.vbs`。负责人选择谭勋策，本轮条数先设为 1–5。
3. Edge 的 `edge://extensions` 重载本目录 `extension` 中的“SA 比对半自动助手”，版本应为 **0.4.3**。刷新已有工作页。旧的桌面助手也需关闭后重新启动。
4. 在桌面点“连接浏览器”并复制配对码。在已登录的 **SA 数据比对 → 比对结果**页扩展中点“连接 SA 比对页”。
5. 自动导入还需要两个独立标签页：在 WOS 文献页扩展中点“绑定当前 WOS 页”；在后台 **数据管理 → 数据导入与批次管理**页扩展中点“绑定当前导入页”。三个页面都保持打开。

无需 Browser Skill 配置、实例 ID、端口 52800 或 API 密钥。程序自身的本地连接端口仍为 8765。同一时间只运行一个桌面助手。

## 自动认领

选择“自动认领”，范围为“待处理”，点“开始自动认领”。只处理谭勋策的单匹配作者认领任务及 DOI/WOSID 双缺失认领任务。

先检查后台处理状态。已处理的仅同步名单；未处理的按 SA 括号编号查唯一人员，再用其已存在的姓名/别名匹配唯一署名。不猜作者、不覆盖别人认领、不自动新增别名。

认领成功回读后填写网页批注，再结案和回写名单。作者不一致使用“已认领”；SA 确认双标识未提交时使用“DOI和WOSID SA未提交；已认领”。无法唯一识别人员、无认领窗口等标为跳过并保存真实原因。

## 自动导入

选择“自动导入”，点“开始自动导入”。范围来自当前负责人名单中的 **未完成、匹配数为零**记录，无需先做 AI 分类，也无需分别按“下载”“检查”“导入”按钮。

程序按顺序执行：后台状态检查 → WOS 检索 → 导出 Full Record TXT → 文件身份和交大署名核验 → 本库查重 → 必要时上传/导入/推送 → 关联平台号 → 必要时认领 → 网页批注及结案 → 名单回写。

推送遵循 PPT：查重“是”，唯一标识及期刊/发表时间/页码/卷期/题名相似度的指定组合，重复元数据“根据优先级合并”，不存在条目“新增”，本校成果“是”。机构为上海交通大学，说明为 `SA补充-名单ID`。

若本库已经有完全对应的唯一文献，关联已有平台号，不重复上传。TXT 和进度日志按名单编号、事实指纹、文件 SHA-256 对应，不采用下载目录中的“最新文件”。

## 范围和结果

- 本轮条数 1–100，按名单记录计数。同一论文可复用一个真实 TXT，但每个 SA 编号单独关联、认领和结案。
- “待处理”不执行已完成或已跳过记录；“重试跳过项”仅执行末尾“是否识别”为 2 的记录；“已完成”只供查看，开始按钮禁用。
- 绿色已完成，黄色待处理，红色已跳过。首个“备注”列写文字，末尾“是否识别”写 1/2，另记“数据来源”。
- 完成必须有网页状态及批注回读，下载或推送成功本身不等于结案。网页原已处理项使用后台实际批注同步名单。
- 明确非交大写“非交大”；WOS 已确认的真实零结果在首个“备注”列写“wos未查询到”，末尾“是否识别”写 2，继续下一篇。它们不冒充成功入库。只有题名匹配、没有 DOI/WOS 强标识的保留待核验，不猜测同一论文。
- 第一作者、通讯作者、第一单位等需要判断的先跳过，不自动改角色。登录/验证码、通信断开或写入结果不明暂停整批，未执行尾部不写成跳过。

点击“暂停”后等待当前回读结束再关闭。超时提示出现时先核验网页，不连续点开始。恢复使用同一入口，已有上传/导入/推送意图会只读续验，不盲目重复提交。

运行时扩展会自动切换到已经绑定并校验过的工作标签页，避免后台网页计时器被限流。请不要同时在这些页面手动操作。

## 保存与恢复

- `log.txt` 保留最近 100 次操作，不是 100 行。
- `runtime/wos-downloads` 保存真实 TXT；`runtime/wos-imports` 保留入库及补录断点。旧资料和密钥没有删除，但旧 AI 页面已退出程序。
- 名单窄范围 XML 回写前备份、校验文件指纹并在保存后重读。不要在程序运行时编辑名单。
- 旧功能源码可从 Git 提交 `b1f812c` 或 `runtime/checkpoints/2026-10-10-minimal/pre-simplify-b1f812c.bundle` 恢复。

0.4.3 将连接/访问检查与检索页面准备分开：不再因暂时没有输入框而挡住整个流程。先激活已绑定的 WOS 标签，再通过页面可见的“高级检索→字段检索”切换并等待挂载，只有唯一字段、输入框和 Search 确认后才提交。准备阶段最多 45 秒，每个导航入口只点击一次；页面切换丢失准备上下文可以续查，Search 提交不重复。上一篇零结果只清理一次，当前论文未检索时不写假零结果或修改名单。

Full Record 下拉框中的 Material 图标不再混入选项文字；仍必须核验实际选中完整记录及单篇范围。下载失败会显示关联下载数和来源校验排除数，不能用历史或无关下载兜底。登录/验证码、5xx、外来弹窗和写入结果不明仍暂停。旧跳过备注不做猜测性批量覆盖。

当前测试证明：合成名单闭环、实际加载扩展在模拟网页中的 TXT 下载与入库、暂停及防重复保护已通过。**尚未完成 0.4.3 在你的真实登录网页上的首条入库验收，不能据此保证真实站点所有变体可自动处理。**
