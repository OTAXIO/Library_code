# 机构知识库 SA 半自动比对助手

已实现：中文桌面弹窗、读取最新名单、按负责人建立队列、精确搜索名单 ID、展示 SA/本库对比、人工核验后写入平台号或处理状态/备注、回读验证、异常暂停、本地断点记录。

**重要：这是首版半自动工具，不是无人值守批处理。已完成离线测试；尚未在已登录的真实后台完成首条写入验收。不要一开始就大批量处理。**

## 1. 启动（当前电脑）

1. 先用 **Chrome 或 Edge** 打开 [机构知识库后台](http://admin.ir.lib.sjtu.edu.cn/#/dataCompare/list)，自行登录，进入「SA数据比对 → 比对结果」。不要使用 Codex 内置浏览器，它不能加载此扩展。
2. 双击本目录的 **`启动助手.vbs`**。它使用本机已有的 Python，以无命令行窗口方式打开助手；不安装软件、不修改浏览器登录配置。
3. 助手会从 `code` 的父目录寻找 `数据比对结果*.xlsx`，按**文件最后修改时间**选最新一份；忽略 Office 临时文件。检查界面显示的文件名、时间和记录数。不符合预期时点击「选择名单」。不会自动下载网页里的新名单；请先从网页导出到父目录。
4. 选择你负责的姓名。默认不选人、不处理全部人员，也不会启动时自动写入。

首次在其他电脑使用：安装 Python 3.10+（含 tkinter），在 `code` 目录创建 `.venv`，安装 `requirements.txt` 后启动 `app.py`。普通终端启动命令是 `python app.py`；双击入口优先使用 `.venv\Scripts\pythonw.exe`，其次查找本机 Codex 配套 Python。若单位策略禁止 VBS，使用本机 Python 运行 `app.py` 即可，无需修改系统安全策略。

## 2. 首次安装浏览器连接扩展（只需一次）

1. Chrome 打开 `chrome://extensions`，或 Edge 打开 `edge://extensions`。
2. 开启「开发者模式」，选择「加载已解压的扩展」。
3. 选择本目录下 **`extension` 文件夹**，不是 `code` 整个文件夹。
4. 回到已登录的比对结果页，点击工具栏的「SA 比对半自动助手」图标。
5. 桌面助手点击「连接浏览器 / 配对码」→「复制配对码」；粘贴到扩展弹窗，点击「连接当前标签页」。
6. 桌面显示「浏览器已连接」后开始。**每次重启助手都要重新配对**。刷新网页后，如连接中断，再点击扩展连接；不用重装。

扩展只申请后台站点与 `127.0.0.1:8765` 权限，只连接一个指定标签页；配对码仅存于扩展本次会话，不是账号密码。不会提取网站 Cookie、登录令牌或密码。若换标签页，先在桌面生成新配对码后重新连接。

## 3. 每条记录怎么做

1. 点击「开始 / 下一条」：精确搜索 `sa_lzk表ID`，打开比对详情，把原文线索和差异显示到弹窗。
2. 按右侧「本条处理指引」核验。Excel 的匹配数、查询方式、审核状态不是事实判断依据；以原文、学者身份和现场数据库核验为准。
3. 根据情况操作：

| 场景 | 工具会做什么 | 你需要做什么 |
|---|---|---|
| 精确搜索、详情对照 | 自动查询并读取，不写库 | 核验 ID、题名、工号、原文 |
| 平台号错误或补充匹配 | 填写并提交你指定的唯一号，再回读 | 先确认同一文献并输入完整编号 |
| 本库元数据错误 | 打开当前唯一条目的原生编辑窗口 | 在原网页修改作者标记、DOI 等，保存并关闭 |
| 需要认领 | 打开唯一条目的认领窗口 | 按工号确认学者身份，再认领 |
| 处理完成 | 写入你确认的备注、设为已处理，再查询验证 | 写清依据，勾选已核验并确认单条修改 |
| 你在网页已经标完成 | 再次只读查询，只更新本地进度 | 先搜索、核验，再点「记录网页已完成」 |
| 匹配多条、合并、导入、别名 | 展示指引，停在人工阶段 | 在原网页操作；工具不自动合并、删除、导入或推送 |
| 未知/错误/超时 | 弹窗暂停，不自动重试 | 排查后关闭编辑弹窗，再只读重查 |

4. 完成元数据修改/认领后，保存并关闭网页编辑窗口，点击「搜索 / 人工处理后重查」。工具不会把“打开窗口”或“你点击继续”当成修改成功。
5. 在备注里记录原文/数据库出处、核验结论及已完成的修改。勾选「我已核对当前 ID、原文与差异，并处理了所有未知情况」。
6. 点击「设置已处理并核验」。再次确认目标、改动和备注后，仅处理当前一条。成功必须回读到「已处理」和相同备注；否则暂停。
7. 成功后默认搜索下一条，但仍停在下一条的人工核验阶段。可取消勾选「完成后搜索下一条」。

“写入平台号”的备注仅保存在**本地操作日志**，平台号编辑接口本身不新增网页备注；最终「设置已处理」时才把备注写入网页。平台号写入后不会自动标完成，必须重新读取详情再核验。

### 固定备注规则（2026-09-22 补充）

| 已核验的情况 | 固定备注 |
|---|---|
| 作者不一致、原来未认领；完成认领、保存并重查确认 | 已认领 |
| SA 的 DOI 和 WOS ID **都**没有提交 | DOI和WOSID SA未提交 |
| 通讯作者错误；按原文修正、保存、重查并确认完成 | 通讯作者修正 |

弹窗备注框上方新增三个同名按钮。先重新查询，再点对应按钮；认领和通讯作者修正需确认已完成。按钮只填入备注，不会提交或标记完成。多个问题用 `；` 合并，不重复添加，例如：`已认领；DOI和WOSID SA未提交；通讯作者修正`。

`已认领` 虽然不足 6 字，也可以原样提交。提交前会重新读取备注相关详情，校验认领结果、SA 双字段缺失及通讯作者标记；详情在确认后改变则暂停。只缺 DOI 或只缺 WOS ID 不使用“双缺失”备注；无法读取字段也不等于字段为空。通讯作者是否正确仍以人工核对原文的结论为准，工具不把 SA/本库两侧一致当作正确性的证明。

从旧版更新后：退出并重启桌面助手；在浏览器扩展管理页对本扩展点击「重新加载」，刷新比对网页，再用新配对码连接。

## 4. 遇到未知情况怎么办

- **查询方式为 3 或其他未知值**：PPT 未定义。先向负责人确认含义并记录依据；不能按普通匹配规则直接处理。
- **无匹配**：核验是否交大成果、题名错误、未发表或本库缺失。未查到文献不是自动完成的充分条件。
- **多条匹配**：先核验是否同一文献；不是看到“匹配两条”就直接合并。重复合并、选主条目、删除均由你操作。
- **写入超时或回读失败**：请求可能已成功，也可能还在执行。不要马上再次提交；等网页请求结束，检查状态、备注、平台号，再点击只读重查。软件不会自动重试写入。
- **页面跳回登录/组件变更/表头变化/编号非文本**：停止，不猜测、不绕过；登录由你完成，适配器变更需要维护代码。
- **有编辑弹窗没关闭**：工具不会替你丢弃未保存修改。请自行保存或取消后再重查。
- **暂停后续**：禁止自动进入下一条；已经发出的单条请求不能撤回。命令执行中不允许退出或重新配对。
- **跳过并记录**：只保存本地跳过原因，不改网页，也不计作完成。可从左侧重新选中继续。

## 5. 名单更新与留痕

- 每次启动读取父目录最新修改的匹配文件；运行中要切换到新导出的名单，请点「读取最新名单」。操作前会校验**当前已加载文件**有没有变化；不会偷偷把队列换成另一份名单。
- 不修改原 Excel。校验所有记录的唯一 ID、表头、长编号文本类型、匹配数量与平台号个数。必要列出现公式时停止，避免使用陈旧公式缓存。
- `runtime/progress.sqlite3` 保存本地状态、核验备注、修改前后快照。它包含工作信息，应按单位要求保管；不上传 Git。
- 重新启动需要重新配对和选择负责人。已完成的相同记录会跳过；源记录内容或所在行发生变化时要求重新核验。未知写入状态不会自动续写。
- 日志不是系统数据库备份。自动写入目前只涉及匹配平台号及处理状态/备注；恢复错误修改应由管理员依据前后快照审查，工具不自动回滚。

## 6. 版本与后续更新

代码独立 Git 仓库位于 `code/.git`，远程为 [OTAXIO/Library_code](https://github.com/OTAXIO/Library_code)。开发开始时发现上一级原有历史包含原始资料，因此另建代码仓库；**不要把包含原始名单的历史推送到此远程**。

关键更新前在 `code` 仓库提交、上传上一阶段，再修改；不要执行强制推送。首次代码生成前已经提交并上传初始化及设计边界。原始 PPT、Excel、浏览器配对信息、数据库、运行日志均不在代码仓库中。

维护者可运行：`python -m unittest discover -s tests -v`；浏览器适配器离线测试：安装开发依赖后 `npm test`，需要本机 Edge 或 Playwright Chromium。测试文件为合成数据；所有浏览器网络请求被测试页拦截，不修改真实网站。

真实扩展的离线全链路测试：`npm run test:extension`。它用隔离浏览器、合成网页及本机 8765 端口验证配对→搜索→写入→回读，运行前请退出桌面助手避免占用端口。共 **61 项检查通过**，具体见 `TEST_REPORT.md`。

## 8. 技能与依据

本次开发按已安装的演示文稿、电子表格、网页操作技能读取资料、划定人工确认边界并核验实现；详见 `SKILL_USAGE.md`。技能是 Codex 的工作指引，不是可由 Python 直接调用的通用库；本工具运行时不需要 Codex、AI API 密钥或额外模型费用，也不会冒充实时调用这些技能。

本工具依赖后台当前 Vue 组件结构；这是未公开承诺稳定的内部界面，升级后宁可暂停也不猜测。使用现有页面自身的检索、弹窗方法处理登录和加密，不复刻认证或直接调用全量/增量比对任务。
